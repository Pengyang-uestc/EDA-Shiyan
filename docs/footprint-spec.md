# 标准封装规格提取表

> 状态：v1.0，2026-11-02
> 用途：把 PPT 要求的“物理规格 → 数据模型属性”写成可核对的一页纸；同时作为标准封装模板（DIP-8、DIP-16、RAD-0.1、AXIAL-0.4）的建库依据。
> 口径：模型、界面、文件统一用 **mil**；表中 mm 仅用于对照机械尺寸。数值为项目约定，按 IPC-7251（通孔）/ IPC-7351（SMD）的思路简化，不声称是标准原件。

---

## 1. 通用约定

| 项 | 约定 |
|---|---|
| 内部单位 | mil，`double` |
| 坐标 | footprint-local，原点在焊盘包围盒中心 |
| 层 | 通孔焊盘用 `top`；丝印用 `top_silk` |
| 焊盘形状 | 1 脚用 `rect`，其余用 `circle` |
| 默认阻焊开窗 | 4 mil（约 0.10 mm） |
| 默认电气间距 | 10 mil（约 0.25 mm） |
| 丝印线宽 | 10 mil（0.254 mm） |
| 安装孔 | 四个模板都不带安装孔；需要时单独加 `MountingHole` |
| 引脚编号 | 从 1 脚开始，逆时针 |

坐标约定：X 向右，Y 向上；原点 `(0,0)` 在两列焊盘的几何中心。

## 6. 规格 → 模型字段映射

| 规格项 | 模型字段 | 说明 |
|---|---|---|
| 封装名 | `Footprint.name` | 如 `DIP-8 W7.62mm` |
| 封装 ID | `Footprint.id` | 如 `dip8_w762`，创建后不可变 |
| 单位 | `Footprint.units` | 固定 `mil` |
| 焊盘编号 | `Pad.number` | 与引脚号一致 |
| 焊盘稳定 ID | `Pad.id` | 1..N，只增不复用 |
| 焊盘形状 | `Pad.shape` | `circle`/`rect`/`oval`/`roundrect` |
| 焊盘位置 | `Pad.pos` | footprint-local，mil |
| 焊盘尺寸 | `Pad.size` | 宽 × 高，mil |
| 钻孔 | `Pad.drill` | mil |
| 阻焊开窗 | `Pad.maskMargin` | mil |
| 电气间距 | `Pad.clearance` | mil |
| 圆角半径 | `Pad.cornerRadius` | `roundrect` 用，其它为 0 |
| 所属层 | `Pad.layer` | `top`/`bottom` |
| 引脚编号 | `Pin.number` | 1..N |
| 引脚名 | `Pin.name` | 默认与编号相同 |
| 电气类型 | `Pin.type`（类型 `ElectricalType`） | 四个模板都用 `passive` |
| 引脚引用焊盘 | `Pin.padId` | 指向 `Pad.id` |
| 丝印线 | `SilkLine` | 层 `top_silk`，线宽 10 |
| 丝印矩形 | `SilkRect` | 本体轮廓 |
| 丝印圆/弧 | `SilkArc` | RAD 本体 |
| 丝印文字 | `SilkText` | 高度 50 mil，旋转 0 |
| 1 脚标记 | `Pad.shape=rect` + 丝印缺口 | 不单独建字段 |

## 7. 报告里怎么写

1. 先放这张规格表，列“参数 / 符号 / mil / mm / 来源 / 模型字段”。
2. 明确写“数值为项目约定，按 IPC-7251（通孔）/ IPC-7351（SMD）的思路简化；DIP-8 为 300 mil 窄体，不是 600 mil 宽体”。
3. 解释两个容易被问的点：
   - 63 mil 焊盘对应 1.60 mm，60 mil 对应 1.524 mm；本项目取 63 mil，保证环宽 ≥ 0.39 mm。
   - 0.8 mm 取整到 32 mil（0.813 mm），比 0.8 mm 略大，保证整数栅格；不写 31.5 mil，避免半个 mil。
4. 附两张图：封装编辑器中 DIP-8 的整体截图；属性面板显示某个焊盘的 `drill/maskMargin/clearance`。
5. 不要声称这些尺寸通过了 IPC 标准认证；写“按标准思路简化”。

## 8. 假设与未覆盖

- 只做通孔封装，不做 SMD。
- 只做顶层；底面变体通过 `Instance.side=bottom` 镜像，不单独建库。
- 不含 3D 高度、热焊盘、泪滴、拼板。
- DIP-16 的引脚坐标规则见 §3.2；如果实现时发现模板生成器更适合“行列循环”，以生成结果与本文坐标一致为准。
- 安装孔不在四个模板内；需要时单独加 `MountingHole`，并跑 `validatePlacement` 检查板框内和禁布区。
