# 实验一 A 部分实现计划

目标：按用户提供的三人分工 PDF，交付可供 B/C 调用的 C++17、Qt6 模型、UTF-8 行式封装读写和元件库。

用户已要求直接实施前述方案。仅实现实验一 A 部分，暂不编写 B 的 GUI 或 C 的工艺规则。

1. 定义数据契约、稳定 PadId、可深拷贝的丝印图元与模型。
2. 先编写 Qt Test：完整 round-trip、错误输入不覆盖模型、错误保存不覆盖文件、库重建及危险路径。
3. 实现带版本头和结束标记的行式格式，使用约定双引号语法和 3 位小数；QSaveFile 原子保存。
4. 实现基于目录的库和可重建索引，文件为事实来源，拒绝不安全 ID 和符号链接。
5. 提供无 GUI 演示、样例、CMake、构建脚本、CI 和 B/C 接入说明。
6. 以 Qt 6.11.1 基线配置，检查工具链、运行验证并明确环境限制。

验收重点：所有图元与样式保真、64 位 ID 不丢精度、Pin 引用有效、中文与引号往返、损坏输入隔离、库路径约束。
