## 1. 测试目标

1. 证明封装数据能“画出来、存下去、读回来、校验住”。
2. 证明板级对象能“导入网表、放置、布局、布线、覆铜、DRC、存读”。
3. 给两份实验报告留下可复现的截图和用例记录。
4. 守住已定决策：mil、稳定 ID、层组、文件格式、命令入栈前校验。

## 5. 集成与手工用例

### TC-01A 五种图元从零绘制并往返

- **前置**：库为空；封装编辑器可用；栅格 10 mil，吸附开启。
- **步骤**：
  1. 新建空封装；
  2. 用丝印线工具画一条 10 mil 线；
  3. 用圆弧工具画一段 180° 弧；
  4. 用矩形工具画本体轮廓；
  5. 用多边形工具画一个闭合三角形；
  6. 用文本工具写 `TEST`，高度 50 mil；
  7. 放 2 个焊盘和 2 个引脚，引脚分别引用两个焊盘；
  8. 把丝印线宽从 10 改成 15；
  9. 保存到库，关闭，重新打开。
- **预期**：五种图元都存在且位置正确；栅格吸附生效；线宽 15 在重载后保持；2 个 `PadId`、2 个 `Pin.padId` 引用完整；无校验错误。
- **证据**：绘制完成、属性面板线宽、重载后三张截图；`EDA-FP 1` 文件头截图。
- **关联**：`validateFootprint`、`core/io`、B 的绘图工具、C 的保存闸门。

### TC-01B DIP-8 模板往返

- **前置**：库中已有 DIP-8 模板。
- **步骤**：
  1. 从模板新建 DIP-8；
  2. 检查 8 个焊盘、8 个引脚、丝印矩形、1 脚方形焊盘；
  3. 保存到库；
  4. 关闭，重新打开；
  5. 逐项对比坐标、钻孔、阻焊、间距、丝印。
- **预期**：8 个 `PadId` 稳定；坐标与 `footprint-spec.md` 一致；重载后无差异；无校验错误。
- **证据**：保存前、重载后两张截图。
- **关联**：`FootprintTemplates`、`validateFootprint`、`core/io`。

### TC-02 非法钻孔被拦截

- **前置**：DIP-8 已保存到库；记录原文件大小和修改时间。
- **步骤**：
  1. 把 1 脚钻孔改成 3 mil（低于 7.874）；
  2. 保存；
  3. 再把钻孔改成 300 mil（高于 236.220）；
  4. 保存。
- **预期**：两次都阻止落盘；提示定位到 1 脚焊盘；磁盘上原文件不被截断或覆盖。
- **证据**：错误提示截图；文件修改时间未变。
- **关联**：`drillOk`、`validateFootprint`、保存闸门。

### TC-03 库增删查

- **前置**：库中已有 DIP-8、RAD-0.1。
- **步骤**：
  1. 搜索 `DIP`，确认只显示 DIP 系列；
  2. 新建 AXIAL-0.4 并保存；
  3. 删除 RAD-0.1，取消一次，再确认删除；
  4. 再搜索 `RAD`。
- **预期**：搜索结果正确；取消删除不改变库；确认删除后列表和索引同步；再次搜索为空。
- **证据**：库面板三张截图（搜索、取消、删除后）。
- **关联**：`LibraryService`、`ILibraryService`、`EDA-LIB 1`。

### TC-04 层组与激活层

- **前置**：板文件已建，至少 4 个层。
- **步骤**：
  1. 新建一个层组，改名为 `Mechanical`；
  2. 调整组间 `stackOrder`，把 `Mechanical` 移到最上；
  3. 改组内层顺序，改一个层的颜色；
  4. 切换底层铜为激活层，画一条走线；
  5. 隐藏底层铜，再显示；
  6. 切换顶层铜为激活层，再画一条；
  7. 保存并重载。
- **预期**：层组名、组间顺序、组内顺序、颜色在重载后不变；第一条走线 `layer=1`，第二条 `layer=0`；隐藏/显示只影响显示，不改模型；面板与画布状态一致。
- **证据**：层组面板调整前后、两条走线属性、重载后层组截图。
- **关联**：`LayerService`、`DocumentContext`、`CanvasWidget`、`EDA-BRD 1` 的 `group` 记录。

### TC-05 网表导入与异常

- **前置**：库中有 DIP-8、AXIAL-0.4；板为空。
- **步骤**：
  1. 导入正常网表（U1、U2、U3、R1），确认实例和网络任务；
  2. 导入含未知 `refdes` 的网表；
  3. 导入网络引用不存在引脚的网表，例如 `NET N003 U1.9 R1.1`；
  4. 导入重复 `refdes` 的网表；
  5. 导入引用缺失封装的网表。
- **预期**：
  - 正常网表：4 个实例、3 个网络，任务列表完整；
  - 未知 `refdes`、`U1.9` 这种不存在的引脚、缺封装：导入中止，板保持原状，错误带行号；
  - 重复 `refdes`：整份导入中止，板保持原状，错误带行号；相关 `NET` 行不再继续解析。
- **证据**：正常导入截图 + 三种错误提示截图。
- **关联**：`NetlistParser`（A）、导入流程（C）。

### TC-06 L/Z 布线与连通

- **前置**：U1、R1 已放置；N001 连接 U1.1 与 R1.1。
- **步骤**：
  1. 用 L 形从 U1.1 连到 R1.1；
  2. 撤销，再用 Z 形重连；
  3. 在异网 N002 的走线上跨接一条 N001 走线；
  4. 从 U1.1 画顶层走线 → via1 到底层 → 底层一段走线 → via2 回顶层 → 连到 R1.1。
- **预期**：L/Z 路径严格正交；同网连通状态变“已连”；异网交叉被 DRC 标记；两个 via 分别连接 from/to 层，底层段通过两个 via 合并进 N001；单个 via 不会让网络假连通。
- **证据**：L、Z、via 链、DRC 四张截图；连通状态面板截图。
- **关联**：`orthogonalPath`、`RouteTool`、`connectivity`、`drc`。

### TC-07 覆铜与避让

- **前置**：底层有 GND 网络；板框内有一块空白区。
- **步骤**：
  1. 在底层画闭合覆铜，指定 GND，间距 10 mil；
  2. 画一条异网走线靠近覆铜；
  3. 画一条同网 GND 走线进入覆铜；
  4. 选中覆铜，删除，再重建。
- **预期**：异网走线被拒绝或标 DRC；同网走线允许接入；覆铜可选中/删除/重建；重建后 clearance 不变。
- **证据**：覆铜区、异网报错、同网接入、重建后四张截图。
- **关联**：`PourTool`、`CopperPour`、`drc`。

### TC-08 板文件保存与重载

- **前置**：板上至少有 2 个实例、2 条走线、1 个 via、1 块覆铜、1 个矩形板框。
- **步骤**：
  1. 把 U2 设为 `side=bottom`，检查焊盘/丝印层 top↔bottom、X 镜像、旋转顺序；
  2. 保存 `.brd`；
  3. 关闭，重新打开；
  4. 对比实例 `refdes`、位置、旋转、side；
  5. 对比走线/过孔/覆铜的 ID、层、网络、点列；
  6. 对比层组、颜色、`stackOrder`；
  7. 另用预置的 L 形 `.brd` 夹具载入，检查显示、越界判断和再次保存。
- **预期**：全部一致；ID 不变；底面实例镜像正确；层组顺序不变；文件头为 `EDA-BRD 1`，单位 `mil`；L 形夹具能载入并原样保存（v1 UI 不要求创建多边形板框）。
- **证据**：保存前后对比截图；底面实例；文件头；L 形夹具载入截图。
- **关联**：`core/io`、`Document::save/load`、`validateOutline`。

### TC-09 多元件网格布局

- **前置**：导入 4 个 DIP-8 实例，板框 2000×1000 mil。
- **步骤**：
  1. 全选 4 个实例；
  2. 执行网格布局，间距 50 mil，列数 2；
  3. 检查包围盒是否重叠、是否越界；
  4. 撤销，确认恢复原位。
- **预期**：4 个实例不重叠、全部在板框内、按行优先排列；撤销恢复原坐标。
- **证据**：布局前后截图；属性面板坐标。
- **关联**：`gridLayout`、`PlaceTool`、`EdaCommand`。

### TC-10 安装孔与禁布区

- **前置**：板框 2000×1000 mil，空白区域足够。
- **步骤**：
  1. 放置安装孔，钻孔 125 mil，金属化关闭，禁布区 50 mil；
  2. 把安装孔拖到靠近板边；
  3. 在禁布区内画一条走线；
  4. 保存并重载。
- **预期**：安装孔完整落在板框内；走线进入禁布区被拒绝或标 DRC；重载后钻孔、金属化、禁布区不变。
- **证据**：安装孔属性 + 禁布区提示截图。
- **关联**：`MountingHole`、`validatePlacement`、`PlaceTool`。

## 6. 失败路径与边界

| 场景 | 预期 |
|---|---|
| 板框内放不下网格 | 返回失败，实例保持原位，不产生半成品布局 |
| 走线起点或终点在板框外 | 拒绝落点或 DRC 提示 |
| via 的 from/to 相同或非铜层 | 拒绝创建 |
| 覆铜多边形自交 | 拒绝创建，提示重画 |
| 保存时磁盘只读/路径不存在 | `QSaveFile::commit()` 失败，原文件不变，提示错误 |
| 载入未知版本 | 拒绝载入，提示版本号，不尝试猜测 |
| 载入重复 ID | 拒绝载入，报行号 |
| 撤销栈为空时撤销 | 无操作，不崩溃 |
