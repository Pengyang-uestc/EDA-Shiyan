本文档对应 `integration/eda` 的根工程，记录 B 组完成的界面、交互、服务接入、测试和截图材料。代码目标仍是 Qt 6.11.1 Widgets、QPainter 和 C++17。

## 实验一：封装编辑器界面与交互

B 组负责的封装界面由画布、元件库、属性和图层面板组成。画布使用统一的 world/screen 变换处理缩放、平移、网格吸附和对象拾取；焊盘可选择、框选、拖动和调整尺寸。属性面板负责编辑焊盘编号、形状、坐标、尺寸、钻孔、阻焊、间距、圆角和所属层。

本轮修复保证：隐藏层的焊盘不会被框选；框选预览使用真实的屏幕坐标；拖动或属性编辑在失败时不会写入文档；绘图模式被关闭后，工具栏按钮与画布状态保持一致。丝印线、矩形和多边形在顶层铜作为当前层时会自动落到对应丝印层，底面同理。

封装保存流程现在调用 C 的制造校验。钻孔、环宽、阻焊开窗、间距、丝印线宽和悬空焊盘等问题会进入错误或警告列表，错误会阻止保存。

## 实验二：PCB 编辑器界面与交互

PCB 画布绘制板框、层组、实例、走线、过孔和覆铜。层面板从 C 的 `LayerModel` 语义映射为 B 的 `ServiceRoles`，形成两级树：组节点只负责结构，层节点负责可见性和当前层。新增的层组、层、颜色和顺序修改均先复制 Board，再调用 `LayerService`，最后作为一条 `ReplaceBoardCommand` 提交。

分析与检查面板分为 DRC 和连通检查两类。DRC 展示 `violations` 与解析失败 `errors`，记录 code、实测值、要求值和对象定位信息；连通检查展示每个网络的物理分量数量、未连通网络、短路和解析错误。双击列表项会在画布中选中对应实例、走线、过孔或覆铜。

正交走线默认使用 `HV`，菜单和快捷键 `Alt+1` 至 `Alt+4` 可切换四种模式。布线会话先保存在临时 Board 中，单击继续添加线段，按 `V` 放置过孔并切换铜层，按 `Enter` 或右键完成。提交时只生成一条撤销命令，因此一次撤销可以完整回退多段走线和过孔。独立的“放置过孔”工具用于没有连续布线会话时的单次换层操作。

## 心得体会

这次整合最重要的认识是，界面能显示不等于交互闭环。层组树、DRC 列表和布线工具都涉及模型、会话状态和撤销栈三层状态，如果只在面板里直接修改数据，画布和存盘结果迟早会分叉。因此本轮把所有持久化修改统一落到 Board 快照和 `ReplaceBoardCommand`，会话状态仍留在 DocumentContext，分析结果只作为只读投影。

第二个体会是占位服务不能长期留在主路径。把 C 的制造校验接入保存流程后，错误能定位到具体焊盘；层模型接入后，面板不再自己拼接组名。这样 B 只处理交互和角色映射，制造规则与层数据保持单一来源。

第三个体会是测试要覆盖行为而不是只覆盖控件存在。隐藏层框选、网表导入后的保存有效性、过孔与多段走线一次撤销，这些问题只有通过行为测试才会暴露。截图自动化和对象定位列表也反过来说明，界面结论需要可重复的输出来支撑。
