# a12cffd 的 core 移植复核

复核基线为 `integration/eda@e782ec8` 和 `feature/pengyang-core@2de9dbe`。两者的根 `core/` 文件 Git blob 完全一致。B 的修复位于 `main@a12cffd` 的实验二嵌套目录，以下是移植后需要逐项验证的行为。

| 文件 | B 的改动 | 根工程复核要点 |
| --- | --- | --- |
| `board_io.cpp` | 引号内回车转义，正整数 ID 拒绝前导零 | 保留 A 的严格标识符匹配、UTF-8 解码及坐标保存精度。检查回车和字面反斜杠加 r 各自能往返。 |
| `footprint.cpp` | 焊盘和丝印层限制为固定封装层 | 保留 `findPadForPin` 和稳定 PadId 映射。检查非法层在写出前被拒绝。 |
| `footprint_io.cpp` | 拒绝裸字段中的双引号和非规范整数，捕获损坏头部的词法错误 | 保留有引号字符串的转义规则和失败时不修改输出的行为，检查错误包含行号。 |
| `library.cpp` | 将封装 ID 和 Windows 保留名称的正则表达式缓存为静态对象 | 保留目录、符号链接、保留文件名及内外 ID 一致性检查。建议以严格结束锚点覆盖末尾换行。 |

当前整合基线尚无以上四处修改。本轮记录是移植前对照，移植后的签收需要 B 的提交和针对该提交重新运行的全量 CTest。
