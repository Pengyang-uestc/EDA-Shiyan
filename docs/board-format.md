# EDA-BRD 1 板文件格式

板文件使用 UTF-8，扩展名为 `.brd`。首条有效记录是 `EDA-BRD 1`，必须声明 `units mil`，最后以 `end` 结束。空行和整行 `#` 注释可出现在任意位置。字段用空白分隔。字符串可用双引号包围，支持 `\\`、`\"` 和 `\n` 转义。未知版本、记录或悬空引用会导致整板加载失败。

| 记录 | 字段顺序 |
| --- | --- |
| `group` | 组 ID、名称、组排序 |
| `layer` | 层 ID、组 ID、名称、类型、`#RRGGBB`、组内排序 |
| `outline` | 点数、依次排列的 x y 坐标 |
| `instance` | 元件位号、库内封装 ID、x、y、旋转角、`top` 或 `bottom` |
| `track` | 走线 ID、铜层 ID、线宽、网络名、点数、坐标 |
| `via` | 过孔 ID、x、y、钻孔直径、外径、起始铜层、终止铜层、网络名 |
| `pour` | 覆铜 ID、铜层 ID、网络名、间距、优先级、点数、坐标 |
| `net` | 网络名、引脚数、各个 `位号.引脚号` |

层类型为 `copper`、`silk`、`mask` 或 `outline`。固定层 0 至 6 依次为顶铜、底铜、顶丝印、底丝印、顶阻焊、底阻焊和板框。自定义层从 100 开始。对象 ID 为正整数，各类型分别保持唯一。未分配的网络写作 `-`。过孔必须连接两个不同的铜层。引用在文件解析后统一校验。元件实例所用封装必须由 `FootprintResolver` 返回，板文件不内嵌封装。

坐标以 mil 表示，Y 轴向上，旋转角以逆时针度数表示。保存时坐标与角度取三位小数，并检查取整后的几何结构。线宽、钻孔和间距等尺寸使用十进制表示。板框与覆铜边界需要至少三个顶点，不重复首点。板框加载后统一为逆时针。

以下最小示例不引用外部封装，可用 `loadBoard(path, {})` 打开。

```text
EDA-BRD 1
units mil
outline 4 0 0 800 0 800 600 0 600
end
```

包含层组、元件、走线、过孔、覆铜及网络的完整示例见 [board-demo.brd](../examples/board-demo.brd)。
