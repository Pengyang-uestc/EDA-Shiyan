# 实验二 A 组板模型与存储

## 实验原理

Board 统一保存板框、层组、板层、元件实例、走线、过孔、覆铜与网络。实例保存位号、封装 ID、坐标、角度和板面，完整封装从库中解析。板内网络通过位号和引脚编号找到封装引脚，再借助 PadId 找到焊盘。这个映射让网表与 PCB 放置过程共享同一套引脚标识。

独立网表的 COMP 记录声明位号和库内封装 ID，NET 记录声明网络和对应引脚。板文件使用 EDA-BRD 1 保存板级对象及其引用。几何函数提供线段与多边形距离和包围盒预筛，供规则层先缩小对象范围，再计算实际距离。底面封装转换按局部镜像、旋转和平移的顺序进行。

## 实验步骤与结果

我先实现板模型和结构校验，随后实现板文件读写、网表解析与引脚映射。板文件保存前检查坐标取整后的结构，加载时解析引用并将板框规范为逆时针。演示程序可以读取由两个元件、一条网络、两条走线、一个过孔和一个覆铜区组成的样例。已有回归覆盖板文件重载、非法保存隔离、UTF-8 网表和底面坐标往返。

## 心得与 AI 使用

板文件与网表承担不同阶段的数据交换，分别建模可以让 GUI 在摆放前读取网表，并让已有板文件继续保存实际布局。几何函数统一以 mil 为单位，避免规则层重复换算。Codex 辅助实现与审阅范围详见 [AI 使用记录](ai-log.md)，运行证据见 [验证记录](verification.md)。
