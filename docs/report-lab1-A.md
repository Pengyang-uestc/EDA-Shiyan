# 实验一 A 组数据与存储

## 实验原理

封装由焊盘、引脚、安装孔和丝印图元组成。焊盘保存几何和加工属性，引脚通过稳定的 PadId 关联焊盘，避免在两处分别维护坐标。封装复制时深拷贝丝印图元，从而使文档快照与编辑中的封装各自持有对象。

项目使用 EDA-FP 1 文本格式保存封装，用 EDA-LIB 1 表示库索引。保存前检查 ID、引用和属性结构，并使用 QSaveFile 提交文件以避免写入中断损坏旧数据。库入口验证封装 ID，再将它映射到库根目录下的 footprints 子目录。

## 实验步骤与结果

首先定义 Footprint 和相关值类型，再实现读写及库索引。读取时检查版本、必要记录、数字格式和焊盘引用，失败时返回错误信息。演示程序可生成样例封装、写入库、重建索引、重载封装并比较编码结果。已有 Qt Test 覆盖稳定 ID、格式错误、深拷贝、异常引用、保存失败和库索引重建。

## 心得与 AI 使用

文件读写中最容易遗漏的是失败后的旧状态，所以验证除了检查成功，还检查失败时模型和原文件的状态。使用 Codex 辅助整理代码与测试，具体范围、验证工具链和运行结果见 [AI 使用记录](ai-log.md) 和 [验证记录](verification.md)。
